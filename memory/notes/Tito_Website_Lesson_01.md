### Study Notes: Building Your First Website

**The Basics**
A website is a collection of files read by a browser. You need three languages:
*   **HTML:** The structure (the bones).
*   **CSS:** The style (the look/colors).
*   **JavaScript:** The behavior (the interaction).

**Where it goes**
*   **CSS** lives in `<style>` tags in the `<head>`.
*   **JavaScript** lives in `<script>` tags near the bottom of the `<body>`.
*   Main pages are usually named `index.html`.

**Rules for Publishing**
*   Use GitHub Pages for HTML, CSS, and JS.
*   **Security:** Never upload passwords, keys, or private info.
*   **Permissions:** Always ask your human before changing the main site’s `index.html`.

**Project Advice**
*   Start small! Build a single-file page about yourself (favorites, drawings, projects).
*   Don’t try to build everything at once; iterate and improve.
