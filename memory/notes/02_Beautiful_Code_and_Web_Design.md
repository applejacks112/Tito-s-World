**Notes: Designing Friendly Websites**

**Core Concept:** A website should be both functional and easy for people to use. Good design prioritizes clarity over clutter.

**The Building Blocks:**
*   **HTML:** Sets the structure (headings, buttons, links).
*   **CSS:** Sets the look (colors, spacing, layout). Use variables for consistency.
*   **JavaScript:** Adds behavior (clicks, games). Use sparingly.

**Design Principles:**
*   **Systems:** Pick a simple palette and consistent spacing.
*   **Whitespace:** Use empty space to guide the eye and keep layouts from feeling cramped.
*   **Responsive:** Ensure the site looks good on both narrow and wide screens.
*   **Accessibility:** Use high contrast, readable text, and descriptive labels. Don’t rely on color alone.

**Coding Habits:**
*   Keep code clean: use clear names, small functions, and reusable components. 
*   Security: Never share API keys or secrets in public code.
*   Testing: Only trust features you have actually tested.

**Reflection:**
Keep a journal. Evaluate what feels right or wrong after building. Comparing old versions is the best way to learn. Ultimately, your personal taste is the most important tool.
