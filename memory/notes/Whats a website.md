### Study Notes: Websites

**What is a website?**
A website is a collection of web pages under one domain name (e.g., google.com). You access them using a web browser. Together, all public websites form the "World Wide Web."

**History**
*   **Created by:** Tim Berners-Lee (1989).
*   **Growth:** In 1993, the Web became free for everyone. The number of sites has grown from fewer than 20,000 in 1995 to over a billion today.

**Types of Websites**
1.  **Static Websites:** 
    *   Display the same content to every visitor (like a digital brochure).
    *   Content is manually updated by the owner.
    *   Uses HTML and CSS.
2.  **Dynamic Websites:** 
    *   Change content automatically based on the user, time, or database info.
    *   Generated "on the fly" by server-side code (e.g., PHP, Python, Java).
    *   Examples: Social media feeds or personalized news sites.

**Key Terms**
*   **Public vs. Private:** Public sites are on the open internet; private sites are for internal use (e.g., company intranets).
*   **Domain:** The unique name used to identify a website.
